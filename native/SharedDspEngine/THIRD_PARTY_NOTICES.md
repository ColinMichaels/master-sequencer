# Third-party notices

## Steinberg VST 3 plug-in interfaces

The focused VST3 validation boundary contains a minimal compatible subset of
the public Steinberg VST 3 plug-in interface ABI. It is used only in disposable
workers to obtain a factory, enumerate class metadata, and run the bounded
generated-fixture parameter/state/offline instance laboratory. Project
Sequencer does not redistribute third-party plug-ins.
The upstream interface source and license are available at
<https://github.com/steinbergmedia/vst3_pluginterfaces>.
