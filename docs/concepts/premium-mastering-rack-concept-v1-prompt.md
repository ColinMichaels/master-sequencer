# Premium Mastering Rack Concept V1 Prompt

Use case: ui-mockup

Asset type: preview-only high-fidelity desktop application concept board

Primary request: Create a polished, shippable-looking concept for Project
Sequencer's Premium / Advanced mastering workspace. Show a realistic dark
19-inch analog mastering rack and a clear input-to-output processor chain that
supports multiple instances.

Scene/backdrop: full desktop app window, charcoal-black professional audio
editor, no outside environment

Subject: left-side vertical routing lane with large readable nodes in this
order: INPUT, PROGRAM EQ 1, BUS COMP 1, PROGRAM EQ 2, TRUE PEAK LIMITER 1,
OUTPUT. Include compact add, duplicate, bypass, reorder, and remove affordances.
The main area shows three physically believable rack units: a 3U brushed
warm-gray program equalizer with stepped rotary knobs and engraved
frequency/gain scales; a 2U deep navy bus compressor with two softly backlit
mechanical VU meters, metal toggle switches, threshold, ratio, attack, release,
sidechain filter and mix controls; a 1U graphite true-peak limiter with amber
LED reduction ladder, ceiling, lookahead, release, oversampling and stereo-link
controls. Include realistic rack ears, screws, subtle metal grain, dimensional
knobs, switch guards, small wear, panel seams, soft reflections, meter glass,
and readable spacing. Add a small BASIC / PREMIUM segmented control with
PREMIUM selected, plus compact exact-value fields beneath the physical controls.

Style/medium: high-fidelity desktop UI mockup with photorealistic
product-rendered hardware surfaces embedded in a precise modern interface

Composition/framing: landscape 16:9, straight-on view, full app window visible,
routing lane on left and rack faceplates centered, no dramatic perspective

Lighting/mood: restrained studio lighting, readable contrast, warm meter glow,
serious mastering-room feel

Color palette: graphite, charcoal, brushed warm gray, deep navy, amber meter
lights, muted cream labels, sparse lime status accents

Text (verbatim): "PROJECT SEQUENCER", "BASIC", "PREMIUM", "INPUT", "PROGRAM EQ
1", "BUS COMP 1", "PROGRAM EQ 2", "TRUE PEAK LIMITER 1", "OUTPUT", "MASTERING
RACK", "EXACT VALUES"

Constraints: brand-neutral original hardware design; large labels must be
readable; controls must look operable and physically coherent; accessible
contrast; realistic rack-unit proportions; preserve a professional software
layout; no fake cables crossing controls

Avoid: real brand names or logos, trademarked product designs, guitar pedals,
synthesizer keys, mixing console faders, neon cyberpunk, excessive grime,
illegible microtext, decorative controls with no function, perspective
distortion, people, watermark
